## 📌 Overview

The **Hotel Management System (HMS)** is a Java-based desktop application developed as a college mini-project to support hotel administration through an accessible graphical user interface (GUI).

The project demonstrates the application of Java programming, object-oriented design principles, and desktop application development to a real-world management scenario.

Its modular project structure provides a foundation for organizing hotel management functionality into maintainable components.

## ✨ Project Highlights

- 🖥️ **Graphical User Interface** — Provides a visual interface for interacting with the application.
- ☕ **Java-Based Development** — Built using Java for desktop application development.
- 🧩 **Object-Oriented Design** — Organized around modular programming and object-oriented principles.
- 🏨 **Hotel Administration** — Focused on hotel management workflows.
- 🛠️ **IDE and Build Support** — Includes project configuration and build files for development and compilation.

## ⚙️ Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- Java Development Kit (JDK) compatible with the project.
- [NetBeans IDE](https://netbeans.apache.org/) or another Java IDE with Ant project support.
- [Git](https://git-scm.com/) to clone the repository.

### 1. Clone the Repository

```bash
git clone https://github.com/Piyush-Gitkhg10/AIP-Mini-Project.git
```

### 2. Navigate to the Project

```bash
cd AIP-Mini-Project
```

### 3. Open the Project in NetBeans

1. Launch NetBeans IDE.
2. Select **File → Open Project**.
3. Navigate to the cloned `AIP-Mini-Project` directory.
4. Select the project and open it.
5. Allow the IDE to load the project configuration and dependencies.

### 4. Build and Run

Use the IDE to clean and build the project, then run the application using the available project configuration.

Alternatively, if Apache Ant is installed and the build configuration supports the corresponding targets, you can use:

```bash
ant clean
ant jar
```

The exact build targets and application entry point depend on the existing `build.xml` and Java source files.
